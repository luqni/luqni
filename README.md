### 🚀 About Me

Saya adalah seorang **Systems Architect & Edge AI Engineer** yang berfokus pada pembangunan teknologi nyata (*The Real Builder*) — merancang sistem cerdas yang berjalan efisien langsung di perangkat lokal (*edge*), mengorkestrasi agen otonom tingkat lanjut (*autonomous agentic workflows*), dan membangun arsitektur backend enterprise yang kokoh dan aman.

- 🧠 **Edge Language Models (SLMs):** Meneliti, melatih (*SFT fine-tuning*), mengkalibrasi importance matrix (`imatrix`), serta menguantisasi model LLM lokal ke format **GGUF 4-bit** agar mampu berjalan kencang di CPU standar dengan konsumsi RAM di bawah 1 GB.
- 🤖 **Autonomous Multi-Agent Systems:** Mengembangkan agen otonom cerdas dengan siklus belajar berkelanjutan (*continuous learning loop*), kristalisasi skill dinamis, dan integrasi protokol **MCP (Model Context Protocol)** untuk eksekusi aksi dunia nyata secara aman.
- 🛡️ **Enterprise Architecture & Security:** Membangun ekosistem backend berkinerja tinggi (Laravel 11, Cloudflare R2, RAG pipelines, Docker, Linux systemd) dengan penegakan standar keamanan ketat (OWASP compliance) dan sistem pemantauan otomatis 24/7.
